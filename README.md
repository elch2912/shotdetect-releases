# ShotDetect – Downloads

Hier liegen nur die fertigen Android-Pakete (APK) der App **ShotDetect** (Treffererkennung auf der
25-m-Präzisionsscheibe durchs Spektiv). Der Quellcode ist nicht öffentlich.

## Installieren

1. Auf dem Handy die neueste Version laden:
   **<https://github.com/elch2912/shotdetect-releases/releases/latest/download/ShotDetect.apk>**
2. Datei öffnen. Android fragt einmalig nach *„Unbekannte Apps installieren“* → für Browser bzw.
   „Eigene Dateien“ erlauben → zurück → **Installieren**.
   Warnt Play Protect („App nicht bekannt“), **„Trotzdem installieren“** wählen.
3. ShotDetect starten und den Kamerazugriff erlauben.

Voraussetzung: Android 8.0 oder neuer, 64-Bit-ARM (z. B. Samsung Galaxy S24/S26 Ultra).

## Updates

Die App sucht selbst nach neuen Versionen (beim Start und über **„Nach Updates suchen“**) und installiert sie
nach Bestätigung. Beim ersten Update einmalig *„Apps aus dieser Quelle installieren“* für ShotDetect erlauben.
Vorabversionen (`-rc`, `-beta`) werden nicht automatisch angeboten.

Jede Datei hat eine Prüfsumme (`ShotDetect.apk.sha256`), die die App beim Update kontrolliert.
